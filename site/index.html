SharkOps

Helm charts, Prometheus exporters and container images for Kubernetes, all Apache-2.0. Each one started as something I needed while running my own cluster.

  • sharkops-universal A general-purpose chart for running any container image, with Service, Ingress, persistent volumes, probes, and environment from ConfigMaps and Secrets.
  • cnpg-cluster A CloudNativePG Postgres cluster with WAL archiving and scheduled backups to S3-compatible storage.
  • oidc-proxy-ingress Puts an in-cluster service behind oauth2-proxy and an Ingress, using any OIDC provider.
  • netpol-coverage-exporter Per-pod NetworkPolicy and CiliumNetworkPolicy coverage, as Prometheus metrics.
  • alertmanager-github-issues Keeps one GitHub issue open per firing Alertmanager alert group and closes it when the group resolves.
